# CS-328 Group 1 Project: COVID-19 Pandemic Analysis & Prediction

Course project for CS-328. Analyses and forecasts COVID-19 spread using several modelling approaches.

## Contents
- `sir_model_global_covid.ipynb` – SIR epidemiological model on global data
- `ridge_regression.ipynb` – Ridge regression baseline
- `xgboost_global_covid_features.ipynb` – XGBoost with global COVID features
- `prediction_zscore.ipynb` – Prediction with z-score analysis
- `Pandemic_Report.pdf` – Final project report
- `Datasets/` – CSV datasets (India COVID data, vaccination, testing, health indicators, HRR scorecards, etc.)

## Getting started
```bash
git clone <your-repo-url>
cd CS-328-Group-1-Project
pip install jupyter pandas numpy scikit-learn xgboost matplotlib scipy
jupyter notebook
```
